## 背景

关联：S1-IDP-026（R168）。复核时有四处单点改动现有用例发现不了，代码本身正确；补用例把这些先后与收尾钉住，并把身份 README「身份修订」一条对会话的说法写准。

## 验收

- [x] 语句闸门支持在某条语句执行完之后停住。连接器回调查到绑定之后停住，其间解除该绑定，放行后不建立会话；把身份修订改为查到绑定之后另行读取时，用例失败。
- [x] 建立会话的事务持有 Person 行锁时（语句闸门停住会话写入）发起重置时的逐租户解除外部身份绑定，放行后解除成功、这个会话被吊销；去掉逐租户解除里的 Person 行锁时，用例失败。
- [x] 身份修订仍为 0 的账号，没有记下修订的票据同样不兑换；把空修订当作 0 时，用例失败。
- [x] 逐租户解除外部身份绑定之后，会话中心的旁路收尾（协议授权族、后通道、Redis 墓碑）照常送达。
- [x] 身份 README「身份修订」一条按实际行为分开写：哪些递增同时吊销会话，哪些只让旧令牌失效、会话照常。
- [x] 每条新用例都做对应的单点突变，确认会失败。
