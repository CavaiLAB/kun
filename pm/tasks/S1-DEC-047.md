## 背景

文档站任务 [S1-DOCS-010](S1-DOCS-010.md) 单列了四个要产品负责人定的问题：网站对外放在哪、前端框架 Qian 的 91 个组件页怎么办、给大模型的入口还补什么、平台档的包外部的人怎么拿。2026-11-26 把这四问连同选项与建议列给产品负责人，他当天答了。本任务登记这四条：原话、他答的问题与当时的选项、整理时的读法、没有定的、受影响的任务与文档。拿掉组件页这一条由 [S1-DOCS-011](S1-DOCS-011.md) 落地，其余三条这一轮只登记。

引号里是产品负责人的原话。他定的与整理时的读法分开写；读法他没有逐句确认。

原话：

> 先确定 Kun 的网站
> 1.我提供域名，部署到 k3s
> 2.C，从站里拿掉。
> 3.按照你的建议把，最终肯定要给 DSH 使用的
> 4.A

第 3 条的「把」按「吧」读。

### 他答的四个问题与当时的选项

1. 「网站对外放在哪？」A，GitHub Pages；B，自有域名，放在现有集群上；C，两边都有。当时的建议是 A 起步、从第一天就用自有域名指过去。
2. 「Qian 的 91 个组件页怎么办？」A，原样留在主导航；B，留在站里、移出主导航、标明已归档；C，从站里拿掉。当时的建议是给人看的照 B，`llms.txt` 里只留一行说明。
3. 「给大模型的入口还补什么？」①使用文档的代码收进仓库，每次发版编译并跑一遍；②`llms.txt` 里的 API 参考收成每个包一行；③按读者拆小文件；④平台 HTTP 接口的 OpenAPI 导出进站点。当时的建议是先①，再②；④依赖接口参考那个任务（[S1-DOCS-002](S1-DOCS-002.md)），排在后面，但要排上。
4. 「平台档的包，外部的人怎么拿？」A，维持现状，装包要 GitHub 令牌；B，平台档也发到 nuget.org；C，只公开接入用的几个包。当时的建议是现在 A，等远程授权接口的客户端包做出来，那些新包从一开始就公开发布。

### 裁定（产品负责人，2026-11-26）

- D1 网站用他提供的域名，部署到 k3s（「我提供域名，部署到 k3s」）。当时的建议是 A 起步，他没有采纳。域名还没有给。
- D2 前端框架 Qian 的组件页从站里拿掉（选 C，「从站里拿掉」）。当时的建议是 B，他没有采纳。
- D3 给大模型的入口照建议补：先①，再②；④排在接口参考之后，但要排上（「按照你的建议吧」）。他另说了一句「最终肯定要给 DSH 使用的」。
- D4 平台档的包维持现状，装包要 GitHub 令牌（选 A）。

### 读法

下面都是整理者的读法，产品负责人没有逐句确认。

1. D1 的「k3s」读作现在已经放着内部文档站的那个集群，仓库里 `deploy/docs-site/` 是它的清单。内部的入口留不留，他没有说。
2. D2 的「拿掉」读作：组件页不再生成，旧地址落到一页说明上，说明页指向已归档的 Qian 仓库与它的标签。只给组件页用的东西（同源的交互演示、离线编辑器、组件交互的浏览器用例、构建时检出 Qian 仓库）跟着拿掉。他答的是「91 个组件页」这一问；站里别的与 Qian 有关的页面（前端 SDK 的页面、讲旧外壳的几页）不在这一问里，没有定。
3. D3 的后半句读作：给大模型的入口，最终的使用方是 DSH，也就是平台的 Agent 运行时。DSH 怎么用上它，没有定。
4. D4 只定了现在维持现状。建议里「以后的客户端包从一开始就公开发布」那半句不算已定。

| D4 | 已定，就是现状：平台档的包只在 GitHub Packages，装包要带 `read:packages` 的令牌；文档里已写明令牌怎么配（S1-DOCS-010 的「在 .NET 里接权限」） | 不用做 |

### 没有定的

- D1：域名是哪个、什么时候给；内部的入口留不留；对外要的公网入口、证书与对外之前的安全评估，没有问。匠心文档站导航里的「Kun」等本仓库的网站有了对外的地址再改（[S1-DEC-043](S1-DEC-043.md) D8），这件事不变。
- D2：站里别的与 Qian 有关的内容：前端 SDK 的页面（`/sdk/frontend/`）、讲旧外壳的页面（`/start/hosts` 等）、首页页脚的 Qian 仓库与许可链接、版本矩阵里的 `@cavailab/qian-*`、「设计与路线」里的前端框架规格。本仓库的旧外壳、界面包与参考应用的远程模块还在用 Qian 已发布的包，以后怎么办没有定（同 S1-DEC-043 D1）。
- D3：DSH 怎么用上这个入口。②做了以后 `llms.txt` 不再逐页列 API 参考，与文档站规范 §7「`llms.txt` 收录每页」的检查怎么对上，做的时候再提。③按读者拆小文件，建议里没有排，做不做没有定。
- D4：远程授权接口的客户端包以后公开不公开，没有定。
