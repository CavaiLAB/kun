<HomeSection id="get-started" title="三条起步命令" lead="构建 Kun 命令行后，可按需安装组件、创建技能；模型调用需先配置网关。">
<CardGrid>
<Card title="① 装一个组件">

```bash
qian add identity authz files
```

在自己的 ASP.NET Core 宿主里组合身份、授权和文件能力。[30 分钟上手 →](/start/quickstart)

</Card>
<Card title="② 配置你的编码代理">

```bash
pnpm exec qian init --template skill-only --id com.example.guide --name Guide --cwd ./guide
```

在空白目录生成含 `AGENTS.md` 和技能内容的无代码组件。[详见下一节 ↓](#agents)

</Card>
<Card title={<>③ 调一个模型 <Badge text="S1·P1" type="info" /></>}>

```bash
curl "$MODEL_GATEWAY/v1/chat/completions" \
  -H "Authorization: Bearer $MODEL_GATEWAY_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "chat-default", "messages": [{"role": "user", "content": "你好"}]}'
```

经模型网关的 OpenAI 兼容端点发一条请求，用逻辑模型名。[模型网关 →](/sdk/ai/gateway)

</Card>
</CardGrid>
</HomeSection>

<HomeSection id="agents" title="配置你的编码代理" lead="Agent 原生表面从 S1 起就是一等公民：组件带的技能、约定与 MCP 可以直接交给编码代理。">
<CardGrid min="220px">
<Card title="Qian 技能">

安装时可通过 `qian add <组件> --surfaces skills --no-code` 选择技能文件。[表面 →](/start/concepts/surface)

</Card>
<Card title="AGENTS.md 约定">

每个仓库与每个包都带 `AGENTS.md`，`qian init` 生成骨架；代理动手前先读它。[ADR-020 D20.9 →](/design/adr/adr-020-component-model-v2)

</Card>
<Card title="Qian MCP">

组件的 `.mcp.json` 表面随组件安装；文档检索 MCP 为 S1 可选；每租户能力门面（S4）。[MCP →](/sdk/ai/mcp)

</Card>
<Card title="提示词模板">

让代理按任务文件工作：读 `AGENTS.md`、认领任务、按验收逐条完成并开 PR。模板见[仓库 pm/README 第 7 节](https://github.com/CavaiLAB/kun/blob/main/pm/README.md#7-怎么下发任务)。

</Card>
</CardGrid>
