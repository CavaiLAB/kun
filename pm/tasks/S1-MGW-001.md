## 背景

> 2026-11-27 补记：照 [ADR-024](../../docs/adr/ADR-024-model-entry-no-gateway.md)，平台不装 Higress；模型请求由平台自己的模型入口转发，是提议。本任务的内容没有改：适配、能力契约与模型目录照旧要做，本任务的写法里也没有 Higress。契约草案（提议）第 7.4 节改成第一版只做 OpenAI 兼容这一个通用的适配，推理服务也先用它接，推理服务专门的适配放后面；照此，下面验收里 GPUStack 的发现可以先经通用的适配做。本任务怎么改写或拆分，仍等 [S1-DEC-044](S1-DEC-044.md) 其余问题的答复（问题 3、6、7），见草案第 10.3、10.4 节。下面的背景与验收没有改。

组件 `qian.model-gateway`（`runtime.form: service`，`Qian.ModelGateway.Abstractions` / `ctx.ModelGateway` + `Qian.ModelGateway`，`model-gateway` 组合包默认挂 `platform`、可选独立 profile）：GPUStack `/v1/models` 发现、健康探测、上下线；`model-capabilities` / `model-governance` 契约（直接用 iClaw 的）；逻辑模型目录（`chat-default`、`embedding-default` 用途槽位）；`GET /api/models`、`GET /api/models/{id}/health`、`POST /api/models:sync`；`IModelCatalog`、`qian.model-gateway.provider/v1` 扩展点、事件 `model.catalog.changed.v1`；密钥 secretRef。范围先 LLM + Embedding（Q17），GPU 归属待拍板，可独立延期。

## 验收

- [ ] UT：目录条目通过 `model-capabilities` JSON Schema 校验
- [ ] E2E：GPUStack 新增一个模型后 `models:sync` 使其出现在目录；下线后健康状态变更
- [ ] UT：`models:sync` 标 `external` + `confirm`，目录查询 `read`；供应商密钥只以 secretRef 出现
