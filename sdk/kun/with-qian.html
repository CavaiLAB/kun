#内核与平台组件

Markdown 链接

Kun 同时提供内核包和平台组件。组件运行时、命令行与目录市场负责装配，Qian 提供前端框架。两档的依赖边界和前端归属见 ADR-023。

#定位

库内的 ProjectReference 指向同一解决方案的源码。首个合并版发布后，外部宿主可按该版本的发布清单安装所需 NuGet 包。组件 ID、CLI 命令与部署 profile 可在组件目录与宿主说明查阅。

#模块与平台插件、seam 的对应

能力通用机制平台集成
组件装载Kun.Runtime、Kun.Plugin.Sdk注册表、生命周期与能力目录在宿主内装配组件
租户与数据Kun.MultiTenancy、Kun.EntityFrameworkCore、Kun.EntityFrameworkCore.PostgreSQL租户与数据共享租户上下文和 PostgreSQL 行级策略
身份与网关Kun.Identity.AspNetCore、Kun.Security、Kun.GatewayKun.Identity.Client、Kun.Identity.Server 与 Kun.Gateway.Shell 分别承接依赖方、签发方和外壳入口
权限Kun.AuthorizationKun.Authorization.Rbac 负责权限判定，Kun.Authorization.AspNetCore 接入 HTTP 与 gRPC
事件与审计Kun.EventBus.Abstractions、Kun.EventBus、Kun.EventBus.RabbitMQ、Kun.Audit.Abstractions事件与审计使用事务内记录和后台投递
配置与文件Kun.Configuration.Abstractions、Kun.Configuration.Apollo、Kun.Storage.AbstractionsKun.Configuration.Platform 提供平台配置，Kun.Files 装配 Local、S3 或 OSS 存储后端
命令与查询Kun.Core、Kun.Mediator平台命令通过 Kun.Plugin.Sdk.Commands 接入调度管道
HTTP 与 gRPCKun.AspNetCore、Kun.Errors.AspNetCore、Kun.Grpc宿主映射端点，同一套错误契约用于平台调用方
可观测、缓存与限流Kun.Observability、Kun.Caching、Kun.RateLimit宿主通过 AddKunObservability() 接入追踪、日志与指标；网关按路由选择限流策略
验证与测试Kun.Validation、Kun.Testing、Kun.Testing.Containers、Kun.Testing.EntityFrameworkCore测试从对应的包取得断言、容器夹具与 EF Core 支持

#canonical API

组件通过 Kun.Runtime 的服务键取得依赖。租户上下文来自 Kun.MultiTenancy，写侧使用 EF Core 的上下文和事务。网关的服务间令牌由 Kun.Gateway.S2sTokenIssuer 签发。文件组件选用 Kun.Storage.Local、Kun.Storage.S3 或 Kun.Storage.Oss。命令审计由 Kun.Audit.EntityFrameworkCore 装配，实体审计拦截器用于非严格上下文。包迁移指南

#强制装配与禁用项

平台档项目和生产宿主按归属接入平台分析器与禁用符号。授权、数据边界与事件发布规则各有正例与反例。严格租户上下文同时装配 RLS 拦截器和租户模型缓存键。生产宿主从已验证身份取得租户，网关在路由上执行认证与限流。网关支持 NativeAOT，平台宿主使用 JIT。构建门禁

#版本与升级

  • 每份指南顶部都标明适用的发布标签。v2026.10.25 的正文链接同仓 Kun #17 审定的文本，后续合并版直接链接标签下的源文件。Kun 文档和 DocFX 内核 API 使用根 CHANGELOG.md 里最新的正式版本；CI 比对二者，不一致即构建失败。
  • 稳定版或正式修复版的包与标签发布、版本日志 PR 合入主干后，本小节和 API 参考在下次构建时更新。beta 提供独立的预发布说明，站点继续使用版本日志中最新的正式版本。
  • 内核和平台代码、文档与任务都在 Kun 仓库维护，前端框架代码在 Qian 仓库维护。
  • Kun 的同日修复版 -hotfix.N 是推送 nuget.org 的正式修复，但 NuGet 按预发布排序、低于同日无后缀版本；最新的发布版按 CHANGELOG.md 里的先后算，不按 NuGet 的排序。
