## 背景

产品负责人 2026-11-27 对《决策表》一次定稿，模型服务的九个问题都答了（[S1-DEC-044](S1-DEC-044.md)、[S1-DEC-049](S1-DEC-049.md)，[ADR-024](../../docs/adr/ADR-024-model-entry-no-gateway.md) §10）。照[契约草案](../../docs/prd/specs/model-service-interface.md)第 10.4 节第 1 项建本任务，自 [S1-MGW-001](S1-MGW-001.md) 拆出。估时是整理者的估计。

范围照草案第 7.1 至 7.3 节：Definition 包 `Kun.ModelGateway.Abstractions`（平台档的契约包）；服务键 `ModelGateway` 与注册表 `ModelGateway.Providers`；适配的接口 `IModelProviderAdapter`，可选的 `IModelDeploymentAdapter` 与 `IModelUsageAdapter`；数据结构；能力描述的 JSON Schema 与校验，能力开关取支持、不支持、不知道三种值，类型的取值可以增加。上游只归平台，`ModelUpstreamContext` 不带租户（已定，ADR-024 D24.8）。接口与结构是草案的提议，实现时照它定稿。

## 验收

- [ ] 包按档位与角色登记（`KunTier=platform`、`KunRole=contract`），带 `PublicAPI.Shipped.txt` 与 `PublicAPI.Unshipped.txt`，过依赖门禁
- [ ] 能力描述的 Schema 加正例与反例，放在 `contracts/` 下模型服务自己的目录里（草案第 10.5 节）；对话类缺上下文长度、嵌入类缺维数时校验不过；`null` 记成不知道，不记成不支持
- [ ] UT：适配注册表同名独占、卸载即撤销；适配组件的清单只写 `global`
- [ ] 上游的鉴权里 `SecretRef` 只收 `secretRef://platform/…`
